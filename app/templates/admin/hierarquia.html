SEU CLIENTE quem paga/usa o PDV

CA — CLIENTE ADMINISTRADOR (role do Usuário)

É um Usuário com role "Cliente Administrador". Representa: o dono do negócio, a empresa que usa o PDV.

  • cliente_administrador_clientes → N estabelecimentos (Clientes)
  • cliente_administrador_tecnicos → N técnicos
  • areas_cliente (indiretamente) → N subclientes
Billing: resolve_tenant_pagador() → usuario.tenant_id

ESTABELECIMENTO Empresa Fiscal

CLIENTE (tabela: clientes) = quem emite NF-e, NFC-e

Campos: nome, cnpj (unique), endereco, cidade, uf, email

Um CA pode ter vários (matriz + filiais):

  • CA "João Restaurantes" → Cliente "Filial Centro"
  •            → Cliente "Filial Shopping"
  •            → Cliente "Filial Aeroporto"
Cada Cliente tem: PDVs, Produtos, Estoque, Vendas, Ordens de Serviço, Notas Fiscais

CLIENTE DO SEU CLIENTE consumidor final

CF — SUBCLIENTE / CLIENTE FINAL (role do Usuário) — vinculado a 1 único Cliente via areas_cliente

Representa: o cliente da empresa fiscal, quem recebe certificados, compra produtos, recebe NF.

Acessa: Portal (/portal) — vê seus certificados, vendas/pedidos, equipamentos, agendamentos.

Escopo: vê APENAS dados do seu Cliente (empresa fiscal)

Observação: A tabela clientes não tem FK direta para tenants. A relação é indireta: Tenant → Usuário (CA) → cliente_administrador_clientes → Cliente. O escopo é sempre resolvido em runtime pela função get_allowed_cliente_ids() em app/core/scope.py.
