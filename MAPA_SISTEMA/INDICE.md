# Índice MAPA_SISTEMA — PDV Ibix

**Uso:** Consulte este arquivo primeiro para escolher **um** mapa e reduzir custo de tokens. Cada mapa é fonte única de verdade na sua área.

**Banco de dados:** PostgreSQL (porta 5432). Variáveis no `.env` (`pdv_solumatica/.env`): `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`. Conexão: `app/database/connection.py` (senha com caracteres especiais codificada na URL). Schema inicial: restaurar dump e `alembic stamp head`; alterações: `alembic revision` + `alembic upgrade head` (sempre no venv). Backup: `scripts/backup_pdv-solumatica.sh` → `/central_solumatica/Backup`.

## Regra para o Cursor

1. Leia **apenas** o mapa indicado acima para a tarefa (evite abrir todos).
2. Se a tarefa envolver banco + API, abra MAPA_DO_SISTEMA (Parte 2) e MAPA_DE_API.
3. Antes de implementar: MAPA_DE_REGRAS (seção 0) indica quando consultar cada mapa.
4. Para otimização de auth/RBAC/permissões: consultar MAPA_RBAC.md (Apêndice A).
